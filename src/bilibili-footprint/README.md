# B 站视频浏览足迹

当前脚本版本：`10.3.1`。

记录列表页中出现过的视频，支持本地搜索、已看标记和悬浮面板。默认最多保存 100 条，可通过脚本菜单调整上限；数据保存在用户脚本管理器本地存储中。

## 安装

1. 安装 Tampermonkey 或 Violentmonkey。
2. 从仓库总 README 点击“浏览足迹”的安装链接。
3. 在扩展安装页确认，然后刷新 Bilibili 列表页。

## 配置与数据

在用户脚本扩展菜单中调整记录上限、计数气泡和已看标记。设置为 `0` 时仅保留当前页面会话数据。清除浏览器扩展数据前，请先确认是否需要保留本地足迹。

脚本匹配首页、搜索等列表页面，并排除视频播放页、收藏列表和官方历史页。Bilibili 页面结构变化可能影响卡片识别。
