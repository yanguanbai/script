# B 站视频浏览足迹

当前版本：`10.3.1` · 作者：Bart · [English](README.en.md)

这个脚本记录你在 Bilibili 列表页真正看到过的视频。它适合“刚才刷到一个视频，但没有点进去，现在想找回来”的场景。记录只保存在浏览器的用户脚本存储中，不上传到仓库或第三方服务。

## 功能

- 使用 `IntersectionObserver` 观察进入视口的视频卡片，不把整页未看到的 DOM 一次性当成浏览记录。
- 保存 BV 号、标题、封面、UP 主、时长和跳转地址；同一 BV 号只保留一条最新记录。
- 右下角悬浮球打开本地足迹面板，支持关键词搜索、标题/作者高亮和新标签页跳转。
- 支持“已看”角标：按下视频卡片后记录已看状态，之后在列表中标记；可从菜单关闭。
- 悬浮球可拖动，松手后吸附到屏幕边缘；长按可切换浅色和深色主题。
- 默认保留 100 条，支持菜单调整为 `0` 到 `3000` 条；超过上限时删除最旧记录。

## 安装

1. 安装 Tampermonkey 或 Violentmonkey。
2. 点击根目录 README 中的安装链接，确认安装。
3. 打开 Bilibili 首页、搜索页或其他列表页，刷新后即可使用。

## 支持范围

脚本匹配 `www.bilibili.com` 和 `search.bilibili.com`，明确排除视频播放页、收藏列表和官方历史页。Bilibili 页面结构变化可能影响卡片识别；这不是脚本能绕开的限制。

## 菜单配置

扩展菜单提供以下设置：

- **最大保留条数**：`0` 表示只在当前页面内保留，刷新后清空；大于 `0` 时跨页面保存。
- **悬浮球计数气泡**：显示或隐藏当前记录数量。
- **已看标记**：控制已看状态的记录和角标显示。

配置写入本地 GM 存储。清除扩展数据会同时清除足迹和设置。

## 隐私与限制

脚本读取列表卡片中的公开页面信息，并使用用户脚本管理器提供的本地存储。它不会替你恢复 Bilibili 已经从页面中移除的卡片，也不会保证适配未来所有页面布局。
